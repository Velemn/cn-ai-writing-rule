# 附录 B：高频修改意见词典

将反馈翻译为可执行动作。修改一句前先诊断是语言、结构、证据、机制还是范围问题；不将反馈简化为同义词替换。

| 反馈原话 | 真实问题 | 立即执行的修改动作 | 完成标准 |
| --- | --- | --- | --- |
| 太AI / AI味太重 | 段首、连接词、对举句、段长和展开方式高度同构，抽象动词多于真实关系 | 扫描全部在范围文本；删除空泛开头和机械总结；拆解对举句；补主语、对象、动作、过程与证据；打破等长段落 | 读者能从内容关系读出逻辑，不依赖“首先/因此/这意味着”等骨架 |
| 段首句有问题 | 首句是抽象判断、标签或意义句，与后文事实脱节 | 先标记本段真正对象和上段形成的条件；用业务动作、事实、矛盾、差异或逻辑承接重写首句；并检查后文是否顺着同一逻辑展开 | 首句已进入实质对象，无需由第二句重新开始 |
| 段首句问题还在 / 又出现了 | 只修了被点名句子，没有将反馈升级为全局规则 | 对整个当前稿执行段首扫描；将“体现了/关键在于/价值在于/随着”等起段集中处理 | 同类问题在授权范围内不再复发 |
| 不够深入 | 只有方向判断、概念定义或事实罗列，没有中间机制 | 逐项追问作用对象、生成条件、传导过程、证据、使用主体、结果与边界；只增加能回答这些问题的内容 | 新增内容增加了关系判断和证据解释，而非只增加字数 |
| 不够专业 / 再专业一点 | 概念边界不清，业务事实、制度、会计或管理工具没有进入解释 | 校正正式术语；将专业方法绑定到具体业务环节、字段、证据、控制、决策或经济后果；删除无功能术语 | 每个专业概念都解释了“在哪个环节解决什么问题” |
| 案例太简单 / 案例没写透 | 只有企业动作和结果，缺少业务过程、信息作用和机制 | 补充真实的业务问题、数据来源、处理环节、产品/信息形成、使用主体、决策或实际效果，并说明它们与主线的关系 | 案例能回答“为什么这些事实足以支持当前机制” |
| 案例写成企业介绍 | 企业背景、产品、获奖和成果罗列多于研究分析 | 压缩无关背景；将每个保留事实对应到问题、机制、证据功能和有限结论 | 删掉任一企业宣传信息都不影响论证；保留的事实均有分析作用 |
| 案例没贴合主题 | 案例真实，但未回答当前标题或研究问题 | 先写出当前标题要证明的命题；为每个案例事实标注证据功能；移动、压缩或删除无法对应的材料 | 每个案例事实都能指向当前命题中的具体关系 |
| 出现了三段式 / 不要死板 | 段数、段首、句长与展开次序被模板统一 | 不是简单将三段改成两段或四段；重新判断内容有几个真实逻辑环节，合并重复、拆分过载、改变起段方式 | 各节的形式由内容决定，不再出现批量同构 |
| 假大空 | 宏大价值判断没有事实、对象、过程和边界 | 删除口号与泛化形容；补上可核验事实、作用主体、中间过程和可观察后果；证据不足就降低语气 | 结论可以由前述事实和机制推出，不超过证据范围 |
| 太多、太杂 / 列太多东西 | 无主线，背景、案例、数据、术语与分类同时堆积 | 说明核心问题和当前章节功能；保留承担核心论证的机制、证据和边界；删除重复背景、平行清单和无功能延伸 | 读者可用一句话复述本节主线，每块信息有明确用途 |
| 内容太少 / 每个点只写了一点点 | 去 AI 或压缩时误删核心因果链和中间机制 | 恢复必要业务过程、证据、作用对象、条件和结果；不恢复重复背景和口号 | 论证链完整，但无低信息密度补字内容 |
| 数据融入不够 | 数据被放在论点旁边，或关键判断没有证据锚点 | 为每个核心判断确定所需证据功能；选可追溯数据嵌入相应机制；紧接解释数据证明什么 | 数据不再是装饰，删掉数据会明显削弱某个具体判断 |
| 数据口径有问题 / 看一下时间点 | 将不同年份、对象、定义或金额性质当作同一指标 | 列出数字—时间—对象—定义—来源对照；分别写入表、评估、授信、融资、提款、合同和交易口径；不确定时暴露差异 | 每个数字均有时点和类型，不再存在假性可比 |
| 你别乱写 / 你需要看资料 | 没有真正吸收指定材料，或将合理推断写成事实 | 停止扩写；重读指定资料的主线、关键机制和数据口径；建立主张—证据对应；删除无材料支持内容 | 新增的每个具体事实都能定位来源，材料的核心机制已进入论证 |
| 你没看上下文 | 孤立修改当前段，造成前后重复、越界或断裂 | 重读上一层标题、直接前后节、前文已形成结论和本节功能；再决定保留、调用、移动或删除 | 本节在全文中有独立任务，与前后节形成推进而非重复 |
| 框架别动 / 你只能改每个点的角度 | 修改越过授权，将语言或内容优化变成标题重构 | 恢复基准稿标题、编号和章节功能；只调整标题下的问题设置、证据、论述角度和段落逻辑 | 新稿的标题体系与基准稿一致，修改意见又得到实质回应 |
| 这不是我要的逻辑 / 整体方向错了 | 分析对象、分类层级或主线本身失效，局部润色无法修复 | 停止局部删改；重新确认题意、建模对象、主线和交付形式；先给出新的结构判断再展开 | 新结构能一句话解释“分析的究竟是什么”，且不继续继承失效层级 |
| 先审查，不要直接改 | 任务模式是诊断，却未经判断直接重写 | 只输出问题、证据、影响和建议方向；等待修改授权 | 交付物是审查结果，不是未经授权的新稿 |
| 直接给我完整稿 | 用户已将任务从讨论/小步修改切换为完整交付 | 依已确认逻辑和材料一次生成完整范围；不继续输出不必要元讨论 | 交付范围完整，且已完成自审 |
| 图表重复 / 没有信息增量 | 只把正文或前图换了一种图形样式 | 先写明该图独立解决的比较、流程、机制、关系或数据问题；与已有图做功能对照；无新功能就删除 | 每张图有唯一论证任务，正文能说明该图带来的新关系或结论 |
| 目录/页码不对 | 只依赖自动计算或源文本，没有检查最终排版文件 | 以最终交付物为对象，逐项对照目录标题、正文标题、编号、层级和实际页码；再用文件总页数做合理性校验 | 无标题文字/层级差异，页码与实际文件一致，总量无明显异常 |
| 修改意见没有真正落实 | 只做了句子润色或形式更换，原结构、证据或内容问题仍在 | 将每条意见翻译为可验证的修改任务；对照修改前后检查问题是否消失；不用“有改动”代替“问题已解决” | 每条意见都能指向明确的文本或格式变化，且原问题不再存在 |

# 附录 C：交付前自审 Checklist

逐项勾选；不适用的项目可标记 `N/A`。

## 任务与结构

- [ ] 1. 交付物严格对应用户当前任务模式：只阅读、审查、讨论、局部修改、完整稿或正式文件。
- [ ] 2. 未超出授权范围，用户明确排除的内容已完全删除。
- [ ] 3. 核心研究问题和主线可用一句话准确复述。
- [ ] 4. 既定标题、层级、章节功能和理论主线未被未授权改动。
- [ ] 5. 每章、每节承担独立功能，与相邻部分形成推进而非换词重复。
- [ ] 6. 标题中的每个核心词都已在正文中得到实质论证。

## 段落与语言

- [ ] 7. 每个段首句直接进入事实、业务动作、矛盾、条件、差异或论证对象，且与后文逻辑一致。
- [ ] 8. 未出现批量“空泛中心句 + 后文重新开始”的段落。
- [ ] 9. 三级标题下的段数、段长和展开次序由内容决定，无机械三段式、四段式或对称结构。
- [ ] 10. 相邻段落存在信息增量，没有连续重复同一判断。
- [ ] 11. 未依赖“首先、其次、此外、因此、由此可见、综上所述”制造逻辑。
- [ ] 12. 已扫描“不是……而是……、只有……才……、不会……而会……”等模板对举句，没有反复使用。
- [ ] 13. “推动、促进、赋能、助力、提升”等抽象动词均已说明具体对象、过程和结果。
- [ ] 14. 无“这种转化、这一过程、这些布局”等悬空指代，重要对象已明确复现。
- [ ] 15. 无不必要的“本节将、前文、本案例、某报告中”等元写作或资料导航语言。
- [ ] 16. 专业概念均已绑定具体作用环节，无术语、机构名称或工具清单堆积。

## 案例、事实与数据

- [ ] 17. 案例说明了真实业务问题、关键事实/过程、作用机制、使用主体与结果，不是企业介绍或产品清单。
- [ ] 18. 每个关键案例事实都与当前标题和核心机制直接对应。
- [ ] 19. 所有企业事实、数字、制度、方法、系统能力和效果都有可追溯来源，无编造、估算、插值或常识补写。
- [ ] 20. 已落地、试点、探索、计划和潜在场景的语气强度已准确区分。
- [ ] 21. 每个数据都有明确论证功能，而非为增加“数据感”而出现。
- [ ] 22. 已核对统计时间、对象、范围、指标定义和经济性质；口径差异未被静默合并。
- [ ] 23. 已在前文充分展开的案例和数据，后文只在承担新分析功能时重复。
- [ ] 24. 对外文本中的客户、合同、个人和商业内部信息已核对公开边界并必要脱敏。

## 文献、图表与最终文件

- [ ] 25. 文献条目可核验，引文真正支持所在论点，文中引用与文后文献双向对应。
- [ ] 26. 每张图表都有独立的比较、结构、流程、机制或证据功能；箭头、方向、层级、概念和数据来源均与正文一致。
- [ ] 27. 目录与正文标题的文字、编号、层级一致；如需页码，已以最终排版文件逐项核对。
- [ ] 28. 最终交付文件已完成格式、分页、图题/表题、数据来源、续表、字体字号、引用和参考文献的最终可视检查。
